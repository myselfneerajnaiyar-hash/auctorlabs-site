# October push attribution links

Use these canonical Auctor RC links when preparing external campaign messages. Copy the appropriate URL into the channel; this document does not send or schedule messages.

| Placement | URL |
| --- | --- |

| Email | `https://rc.auctorlabs.in/signup?utm_source=email&utm_medium=email&utm_campaign=oct_push` |

Blog links are generated with `utm_source=blog`, `utm_medium=organic`, `utm_campaign=oct_push`, and the current post slug as `utm_content`. Website buttons use `utm_source=website`, `utm_medium=button`, `utm_campaign=oct_push`, and their button ID as `utm_content`; see the mapping in the website source and `scripts/app-attribution.test.mjs`.

Paid acquisition tags remain `utm_source=ig` or `an` with `utm_medium=cpc`; this change does not rewrite paid campaign links.
